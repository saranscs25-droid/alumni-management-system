# Alumni Management System

A Java-based Alumni Management System designed to manage alumni details, events, registrations, and career information efficiently.

## Features
- Admin Login
- Alumni Profile Management
- Add, Update, Delete, and Search Alumni
- Event Management
- Event Registration
- Career and Job Search
- Dashboard
- MySQL Database Integration
- CSV Export

## Technologies Used
- Java
- Java Swing
- MySQL
- JDBC
- MySQL Connector/J

## Requirements
- JDK 17 or later
- MySQL Server 8.x
- MySQL JDBC Driver

## How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Configure MySQL details in `db.properties`.
4. Execute `database.sql` in MySQL.
5. Run `run.bat` on Windows.

## Purpose
The main objective of this project is to simplify alumni data management and improve communication between alumni and educational institutions.
